# Party App - Computación Móvil 2026-1

![Kotlin](https://img.shields.io/badge/Kotlin-2.0.21-purple.svg)
![Compose](https://img.shields.io/badge/Jetpack_Compose-Material3-green.svg)
![MVVM](https://img.shields.io/badge/Architecture-MVVM-blue.svg)

**Party** es una aplicación de descubrimiento de eventos nocturnos que optimiza el acceso mediante pre-reservas y validación por códigos QR.

## Funcionalidades (Entrega Semana 9)
* **Discovery Feed:** Exploración de eventos mediante tarjetas interactivas con carga de imágenes remotas (Coil).
* **Smart Wallet:** Gestión de reservas personales con persistencia de datos.
* **Navigation:** Sistema de rutas desacoplado entre Feed y Billetera.
* **Architecture:** Lógica de negocio centralizada en ViewModels con estados reactivos (StateFlow).
